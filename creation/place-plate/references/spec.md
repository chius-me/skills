# spec.json

坐标归一化为 0–1，相对 **EXIF 旋转后的照片**；左上角为 `(0,0)`。原图路径相对 spec 文件，也可用绝对路径。

最小可用示例（下列坐标仅演示结构，必须按照片重新放置）：

```json
{
  "base": "base.jpg",
  "labels": [
    {"text": "MACAU", "x": 0.15, "y": 0.09, "role": "city", "align": "left"},
    {"text": "GRAND\nLISBOA", "x": 0.74, "y": 0.29, "role": "place", "align": "left",
     "target": {"x": 0.66, "y": 0.35}}
  ]
}
```

## 地名与引线

- `text`：准确文案，支持 `\n` 换行。除 `caption` 外拉丁字母转大写。
- `x, y`：横向锚点与整组文字的垂直中心。
- `align`：`left`、`center`（默认）、`right`；决定 `x` 对应文字左缘、中心或右缘。
- `role`：默认 `place`。下表为 1600px 宽照片的字级，随画幅宽度同比缩放。
- `target: {x, y, color?}`：地物位置；自动从文字框边缘向终点画细实线。`color` 可为 `white`（默认）或 `red`。红色只给可靠拍摄点，整图最多一个。
- `dot: true`：在文字下方放一个点，不带引线。不能与 `target` 同用。

| role | 字号 | 用途 |
| --- | ---: | --- |
| city | 40 | 地区标题 |
| place | 30 | 主要建筑、景物 |
| water | 34 | 水域名 |
| region | 20 | 简图地名 |
| caption | 18 | 译名与短注 |

字号和字距集中在渲染器 `ROLES`，不在每份 spec 里任意堆样式。中文自动使用较窄字距。需要极长标题时先换行；不要直接调小所有文字。

## 轮廓

```json
"guides": [
  {"style": "dotted", "points": [[0.2, 0.3], [0.22, 0.35], [0.24, 0.4]]}
]
```

`style` 支持 `dotted`（默认）或 `solid`。每段至少两个点，遮挡处拆成两段。点状线的间距按路径长度计算，不受控制点多少影响。渲染器不进行自动描边或修正错误坐标。

## 区位简图（可选）

```json
"inset": {
  "x": 0.1, "y": 0.1, "w": 0.2, "h": 0.15,
  "strokes": [],
  "labels": [{"text": "地区名", "x": 0.5, "y": 0.5}]
}
```

`x,y,w,h` 相对照片；`strokes` 每条是简图内部的 `[x,y]` 点数组；`labels` 内部坐标也相对简图，支持 `dot`。框必须完整落在照片内。空数组仅说明结构，不是可交付地图。

先取得边界并按区域大小选择投影。小范围可近似用 `X=经度×cos(中心纬度)`、`Y=纬度`；范围较大时使用适合该区域的地图投影。将投影结果 **等比** 缩放到简图框的实际像素宽高内并居中，纬度向上。不要分别把横纵坐标拉满 `[0,1]`。同一变换用于边界、地名和相机点，保留周围留白。

简图中的红点由顶层 `labels[].target` 绘制：

```text
photo_x = inset.x + map_x * inset.w
photo_y = inset.y + map_y * inset.h
```

在输出目录另记数据来源、覆盖范围与相机位置依据。渲染器只保证几何绘制，不验证地理正确性。

## 指北针（可选）

`"compass": {"x": 0.9, "y": 0.1, "north": 0}`。`north` 是从画面向上顺时针到真北的角度。箭头及 N 共同旋转。普通仰拍没有这种平面方向，不添加。

## 验收

`--strict` 检查文字的实际边界，留出画面短边 2.5% 的安全边距，并拦截文字框重叠。控制点、标签坐标与数值类型也会校验。线条遮挡、对比度、地图准确性和字体是否包含全部字形仍须看图确认。
