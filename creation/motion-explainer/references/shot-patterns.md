# 参考片里的六种动作

这些时间码对应《为什么只有 Google 是最伟大的科技公司》本地版本，全长 7 分 56 秒。可独立使用下面的镜头说明。换题时要保留的是观众能追踪的信息变化。原作者使用的软件和素材工程尚未证实。

| 适合回答的问题 | 原片时间与观察 | 换题后的制作决策 |
|---|---|---|
| 我该比较谁？ | 00:00–00:39，几家公司先各自以代表物亮相，最后在同一排相遇。07:44–07:56，多个产品重新聚拢，回到搜索框。 | 给每个对象一个能辨认的记号。开头用同一构图提问，结尾让观众带着新知识重新看它。比较对象多时分批引入。 |
| 哪个动作带来了结果？ | 01:04–01:06，鞋留在原位，圈选线完成后才出现结果卡。 | 让动作准确落在对象上，结果从动作结束的位置或邻近区域出现。切掉装饰性光效后，操作顺序仍应可见。 |
| 输入换了，结果怎样变？ | 01:06–01:10，天气、算数和换算共享一个搜索框与答案区。 | 固定输入和输出的位置，先换输入，再揭示对应结果。可用于资格规则、单位换算和分类机制。 |
| 这个数量究竟有多大？ | 01:10–01:16，搜索量停在终值，再转入容量对照。 | 单位与最终值一起稳定下来。有可比基准就同时呈现；没有历史序列时，滚动数字仅作揭示，勿画成时间趋势。 |
| 哪个关系改变了？ | 04:32–04:48，词块先排成句，再变成网络。一个词换掉后，高亮连线转向；同一组关系随后变成矩阵。 | 比如演示换乘方案时，两端车站留在原处，一处线路状态变化，推荐路径随之改道。观众读懂旧布局后，再把线路图变成到达时间的对照表。 |
| 两个读数为何一起变化？ | 07:26–07:28，请求量曲线与服务器格子同时变化。 | 让两个视图使用同一组数据或明确写出的机制。若真实响应有延迟，就把延迟画出来。仅有相关性时，图注和旁白也只说相关。 |

原片机器分段的中位时长约 1.97 秒。切点靠近估算拍点的比例约 24%，与工具的基线 26% 接近。功能演示可以快切，新的关系和需要对照的数字则要留够读数时间。配乐、字幕和少量音效已足以支撑这条参考片；换成口播片时，重新按说话人的语速定时。

## 换题练习：极端值为什么有时不改变中位数？

用一组已经排好序的示例数据。三张数字卡 3、5、7 始终可见，中央位置用细框标出。观众读完“把最大的数换掉，会怎样？”后，仅最右卡由 7 变成 99，在卡下保留“原值 7”。末帧能同时读到新数列和“中间这个数仍然是 5”。随附样片用一小段原创拨奏配乐，换值前留空，数字落定时短音接入，结论出现时和音展开。可以静音回看，检验图形能否独立解释这个例子；若要解释中位数何时会变，下一镜需要展示中间位置上的数发生变化。
