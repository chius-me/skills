# 色块编辑设计

用色块划分信息、用字体建立层级、用一个清晰主体聚焦主题。保留杂志式排版的张力，同时让内容易读。主题、语言、平台和工具不限；用户指定的视觉方向优先。

## 确定范围

- 从现有材料提取用途、文案、素材、画幅和交付格式。信息足够就开始，只询问会实质改变结果的缺项。
- 单张作品聚焦一个主题；系列按内容决定页数，每页承担一个信息任务。已有选定方向时直接延续，无需重新探索封面。
- 需要比较方案时，固定文案和素材，每版主要改变构图或配色，便于判断差异。
- 局部改版保留有效设计，只调整受影响页面，另存版本并注明替换关系。

## 视觉语言

| 要素 | 设计起点 |
| --- | --- |
| 色彩 | 2–4 个主色：背景、深色文字、强调色，必要时加辅助色；小字放在高对比纯色区域 |
| 字体 | 标题默认用有粗细对比的衬线体，中文可用宋体／明朝体；正文以清晰为先，避免把衬线理解成书法或手写 |
| 构图 | 一个主视觉配少量大色块，选择不对称双区、标题带加内容分区，或单主体配短文 |
| 层级 | 用字号、对齐、留白和分区区分标题、正文、注释；放不下时精简或拆页，不持续缩小字号 |
| 质感 | 平涂、明确边界，可加少量纸感；装饰与主题有关，不默认堆叠贴纸、图标或立体效果 |
| 画幅 | 按用途确定，未指定的社交图文可从竖版 3:4 起步；关键文字距边缘约 5%，为实际裁切留余量 |

没有配色方向时，可从赭橙 `#EF783B`、深青绿 `#124C49`、奶油白 `#FFF2D9` 起步；它是可替换的示例，不是固定品牌色。

封面通常只放主标题和主题视觉。内页用短标题与少量信息区展开，系列统一字体、色彩和对齐关系，允许各页采用不同构图。

## 素材与制作

1. **先看素材。** 区分内容参考与风格参考：前者决定主体，后者只提供配色、字形和构图方向，不复制其中无关的文字或物件。
2. **保留识别特征。** 照片可裁切、清理背景或简化色阶，但保留主体轮廓、比例与关键细节。需要准确呈现的包装、标志和细字优先保留原图或用可编辑排版，不依赖模型重画。
3. **按交付选择工具。** 图片生成或编辑使用当前环境支持的相应工具；精确文字、指定字体或可编辑稿使用适合的排版工具。遵循工具自身要求，不绑定供应商。没有所需能力时交付明确标注的设计方案或提示词，不声称已完成出图。
4. **保持系列一致。** 采用已选作品作为风格参考，另附每页内容素材；独立候选方案之间不互相作为风格参考。
5. **有针对性地修正。** 文字、主体或布局出现问题时修改对应部分并复查整页。连续两次修正无改善，就调整构图、减少信息或更换制作方式，说明仍未解决的问题。

## 图像提示词骨架

仅在使用图像工具时采用，替换字段并删除不适用项。参考图通过工具支持的方式实际传入，不能仅写文件名。

```text
制作：[用途、页码、画幅或尺寸]，输出平面成品。
风格：大色块、清楚的文字层级、[字体形态]、[照片／插画处理方式]。
配色：[颜色及各自用途]。
参考：[每张图是内容参考还是风格参考，以及应保留的特征]。
构图：[主标题、主体、正文的位置与阅读顺序]。
准确文案：[逐项列出全部需要出现的文字与数字]。
约束：[本次必须保留的主体特征、适用条件、安全边距]。
若为改图：[修改区域与目标，以及应保留的内容]。
```

只放本页需要的信息，不让模型自行补充事实。需要严格使用字体文件时，通过排版工具实现；提示词中的字体名不能证明实际采用了该字体。

## 检查与交付

- 对照文案检查错漏字、数字、读序和遮挡；缩略图可辨主题，完整尺寸可读正文。
- 对照内容参考检查主体，避免把生成的标签或细节当作事实来源；有时效的信息保留必要条件与核对日期，不虚构亲历。
- 读取输出文件的实际宽高，检查裁切和比例，不从提示词推断尺寸或拉伸成品。
- 按阅读顺序交付成品，局部修改注明替换页；仅按需附文案、提示词或可编辑源文件，说明未解决的问题。
