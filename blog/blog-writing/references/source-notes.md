# 阅读样本与风格来源

采样日期：2026-11-08。以下是对四个博客中 13 篇文章的定性阅读记录，覆盖项目、运维、排障、测试、源码和个人复盘。长源码文按开头、代表性解释段与收尾抽读；不是全站普查，也不代表作者所有时期的风格。

只归纳表达方法，不收录原文段落。观察与本 skill 的编辑建议分开看：参考文章中的技术判断、推荐和历史数据没有在此逐项验证，不能借风格参考进入用户的新文章。

样本里的句子常由“原先怎样—后来遇到什么—所以怎么改”推进，技术词与口语共存。采用其问题驱动和坦诚取舍；不默认继承激烈措辞、半角标点、删除线密度或专属口头禅。

## 综合后的默认方向

本 skill 的默认方向是：具体问题开场，必要细节支撑，取舍说清，个人感自然保留。它是基于样本做出的编辑选择，不是四位作者都遵循的共同公式。

需要增加趣味时，优先恢复作者原本有意思的观察；需要增加深度时，补足机制和证据；需要变短时，压缩重复解释。不要靠照搬口头禅、制造经历或固定写作比例实现这些目标。
