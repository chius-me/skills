# Shields.io 徽标规范与速查表

为保持全库风格统一，所有徽标一律遵循以下格式约定。

---

## 1. 核心约定

- **参数统一**：使用默认的 `style=flat`（扁平风格）。
- **必须可点击**：每个徽标都必须具备明确的超链接跳转（避免死链或无链接展示）。
- **左标题与右文案**：标签（label）简短，信息（message）精确。
