# SPECIAL · 让专题有自己的玩法

原站用同一套刊头、栏目字标、白色面板和图文目录容纳 11 个专题。目录里的横幅缩略图有细墨框，图下是短标题，右缘的小黑圆箭头指向详情。入口卡片承担识别与跳转，进入专题后再改变画幅、阅读宽度和操作方式。新项目可以用自己的材料对号入座。[特别企划目录](https://city-the-animation.com/special/)

| 手上的内容 | 适合的编排 |
| --- | --- |
| 有票务、周边和注意事项的活动 | 用活动海报开场，在同一页内以短锚点连到各段。内文限制行宽，绿色小标题下放时间、票种或商品详情。滚到长页中段时可用底部轻导航换段，把已结束的票务写成明确状态。[活动页](https://city-the-animation.com/special/event/) |
| 有日期、作者和草图的制作手记 | 索引用小图、绿色日期、题目和署名组成紧凑条目。点开后沿用栏目框架，加入手记自己的字标和小插画。正文按创作过程穿插图文，图片说明贴近对应素材。[手记索引](https://city-the-animation.com/special/production-note/) · [一篇手记](https://city-the-animation.com/special/production-note/01/) |
| 系列画作、片尾卡、可下载头像 | 片尾卡用“单幅作品＋回次”连续排；概念图保留每幅署名；画廊用绿色小标题分组，图注随图走。头像赠品按主题分组，以同尺寸小方格密排，每枚对应其文件。先判断读者是在欣赏整幅作品，还是在快速挑一枚下载。[片尾卡](https://city-the-animation.com/special/end-card/) · [概念图](https://city-the-animation.com/special/concept-visual/) · [画廊](https://city-the-animation.com/special/gallery/) · [头像赠品](https://city-the-animation.com/special/present/) |
| 需要观众先自己观察的游戏 | 找不同先给两幅题图，答案藏在珊瑚色展开条后，揭晓图用标记指出差异。让读者能再收起答案。窄屏依然保留对应的画幅与取景，才便于比较。[找不同](https://city-the-animation.com/special/machigaisagashi/) |
| 现场报道、演员寄语、主创访谈、节目档案 | 报道用事件推进文字，穿插现场照和视频。演员短评用小头像、角色和演员名标明说话人；主创视频用各自的封面。系列节目按期展示播放状态，并把主持和来宾归到对应一期。[现场报道](https://city-the-animation.com/special/cast-talk-report/) · [演员寄语](https://city-the-animation.com/special/cast-comment/) · [主创访谈](https://city-the-animation.com/special/staff-comment/) · [系列节目](https://city-the-animation.com/special/adataras-living-room/) |
