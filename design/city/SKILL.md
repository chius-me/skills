# CITY 通用设计理念 · Four-Color Everyday Storytelling

用白纸与深墨立住阅读秩序，用四色平涂和日常小动作讲出人物性格。灵感源于新井圭一原作《CITY》与京都动画《CITY THE ANIMATION》的绘本群像美学：哪怕主题不是动漫本身（例如独立工具、社区导览、播客封面、活动海报或产品短片），也可以借这套视觉语法做出明快、轻盈、耐看且有生活幽默感的作品。

> 若任务是设计、开发或统一 **CITY 相关网站 / Web 应用**（特别是 `*.city.chius.dev` 系列站点），先通读本理念，再严格按 [CITY 网站设计规范 (`city-web`)](../city-web/SKILL.md) 执行工程结构、共享顶栏与互链要求。

## 三条核心理念

1. **微因果的日常群像**：好的画面不止是孤立摆拍，而是用一个瞬间牵动下一件事——书架顶滑落的书、交叉口擦肩的居民、刚要开口的反差表情。远看抓轮廓，近看读故事。
2. **白纸墨骨与四色节拍**：大面积干净纸白/暖纸（`#FFFFFF` / `#FFFDF9`）承载主体信息与文字；高辨识度的深墨线（`#141419`）与硬边偏移投影负责立住边界；**杏黄 `#F7B647` · 樱粉 `#F09CB4` · 草绿 `#99CB77` · 珊瑚 `#EE847D`** 按固定 **C-I-T-Y** 色序担任导航、编号、圆点与情绪强调，严禁无节制五彩乱涂。
3. **圆厚字头配冷面旁白**：标题与招牌字母圆润厚实、带黑边轮廓；正文与数据保持稳定清晰的圆体无衬线基线；讽刺、吐槽或故事背景转折，常反差落进深灰蓝（`#33333F`）旁白框中配亮黄/白字，制造新井式脱线喜剧张力。

## 五项基础视觉语法

| 维度 | 核心规范与色值 | 使用边界 |
| --- | --- | --- |
| **纸、墨与旁白底** | 纸面 `#FFFDF9` / `#FFFFFF`、奶油浅底 `#FAF6EE`；主墨色 `#141419`；旁白深灰蓝 `#33333F`。 | 正文区安静留白，可叠极淡错落彩字纹样（边缘或低不透明度）烘托空气感，不干扰正文阅读。 |
| **C-I-T-Y 四色节拍** | 杏黄 `#F7B647` → 樱粉 `#F09CB4` → 草绿 `#99CB77` → 珊瑚 `#EE847D`；交互点缀晴空蓝 `#1395EA`、浅天蓝 `#C4E4F5`、警示红 `#DD5549`。 | 章节圆点、菜单瓷砖、标签序列固定走 `C→I→T→Y` 顺序；单个核心按钮只取一种强调色配深墨字或深墨底反白。 |
| **字标与字体层级** | 展示字标饱满微圆，常用黑描边外扩（`paint-order: stroke`）；正文选用开口清楚、多字重齐备的圆润无衬线体（`M PLUS Rounded 1c` + `Noto Sans SC`）。 | 性格化造型只给 `2–8` 字的短标与字标，连续正文、数字、日期与双/三语混排保持平直清晰。 |
| **墨线轮廓与大圆弧** | 卡片与重要入口用 `2px–3.5px` 实墨边框配 `2.5px–6px` 硬边偏移投影（`#141419`），不用模糊重阴影。常以单处醒目大圆弧（`28px–36px` 或胶囊半圆）切出动感。 | 拒绝在带粗墨框的卡片内部再嵌套另一层粗墨框（防“盒中套盒”），内部分区用极浅灰线或浅奶油底即可。 |
| **手绘与写实混编** | 赛璐珞平涂插画带轻微手绘线宽起伏与纯色块；需要展示实物照片或软件截图时，加相同比例的墨线窗框与统一角度的圆角卡片衔接。 | 绝不把生硬的高清截图直接贴在手绘纸面上，用相框描边、四色圆点标牌与统一投影把两者融进同一张纸。 |

## 按创作载体决定构图与节奏

- **全景导览与地图**：让带空间因果的场景占满视野；主路径或连线串起关键人物/地标，并在角落为搜索、缩放与说明保留不遮挡主体的清晰立足点。
- **高吸睛封面、海报与缩略图（兼顾 `16:9` / `4:3` / `3:4`）**：先用 **1/6 手机缩略图尺寸** 验证第一眼可读性。主标题控制在短句，放大字号并用粗墨描边＋硬投影托出，不堆密集小字；横版封面若需同时投喂 `16:9` 与 `4:3` 信息流（如 B 站 / YouTube），把核心文字与主视觉收束在中央 `4:3` 安全区，左右留作呼吸扩展或次要景别；竖版 `3:4` 上下分段给字标、主画面与单句钩子。
- **图鉴、卡片与目录页**：使用一致裁切比例（如 `4:3` 或 `1:1`）的头像或近景照配粗墨圆形/圆角框；每张卡按「色标徽章 → 主标题 → 副名/声优/参数 → 一句性格短语」固定秩序排列，主次分明。
- **漫画分格与步骤说明**：采用单一阅读主轴，多格连续保持相似机位视角，仅让当前变化或强调的部分独占 C-I-T-Y 强调色；仅在语气明显转折处放入 `#33333F` 旁白框、拟声字或探出边框的看板元素（如白耳猫/小物件）。
- **宣传片与动态短片**：用高反差漫画分镜格或“问题冲突”开场（1–3 秒立住人物与场景），再用 `cubic-bezier(0.65, 0.05, 0.36, 1)` 般明快干脆的推拉/滑屏运镜切入真实界面交互、星图漫游或成果展示；结尾以 C-I-T-Y 四色圆点弹跳、字标定格与一句凝练口号收束。

## 跨载体联动准则

把同一个企划拆成多种物料时（如网站＋视频封面＋宣传折页＋导览手册），**共享四样东西**：LOGO 轮廓与副标格式、C-I-T-Y 四色顺序、`#141419` 墨线粗细与硬投影方向、`M PLUS Rounded 1c` / `Noto Sans SC` 字阶；但**分开读者第一眼看到的重心**：封面只给痛点标题与单一主视觉，说明书/手册给按步近景与序号，网站给直接可点的功能入口。

## 交付前三问（通用评审）

1. **遮住插画与底纹**：标题、时间、重点数字或核心行动号召是否依然一秒可读、不被装饰抢走对比度？
2. **退后两步 / 缩成手机缩略图**：主视觉轮廓能否立刻认出？若四处都在尖叫，把四个彩色收敛回单一色序焦点，其余区域退回白纸。
3. **跨物料并排对比**：把纯文字页面、截图界面与海报放在一起看，它们是否通过字形、墨线、四色圆点和直边对齐显出“同一座城市出品”的家族感？
