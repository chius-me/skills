# 反模式、质量门禁与评审规范

用于 `tamako-web` 站点开发前排雷、改版自查以及独立设计评审。

## 一、玉子市场网页反模式避坑表

| 严禁做法（Anti-Pattern） | 破坏了什么原则 | 正确替代方案 |
| --- | --- | --- |
| **使用 `#000000` 粗黑描边与硬直角黑影** | 把《玉子市场》做成了美漫波普或《CITY》粗墨风，丧失温柔糯米手账质感 | 边框用柔粉/暖金/豆沙细线（`1px–2px`），分岛用纯白留白或极轻暖棕影（`rgba(142, 76, 40, 0.08)`） |
| **深色毛玻璃 / 赛博紫霓虹渐变** | 与兔山商店街日光暖纸、和果子色盘南辕北辙 | 保持 `#FDFFF2` / `#FBF8F1` 暖底，顶栏仅用 `rgba(255, 249, 250, 0.92)` 淡樱磨砂 |
| **复制 2013 原站 `viewport: width=980`** | 手机访问强制缩到极小字号、产生横向滚动溢出 | 固定使用 `width=device-width, initial-scale=1`，落实 `1320 / 834 / 768` 三段断点 |
| **图片精灵配 `display: none` 藏文（无真实可读 DOM）** | 读屏器失去文本或破坏语义结构，缩放模糊 | 标题、导航、日文/中文短标使用真实 `Zen Maru Gothic` 文本与内联 SVG 装饰 |
| **全局 `a:focus { outline: none }`** | 键盘 `Tab` 导航完全丢失焦点位置 | 使用高对比 `:focus-visible` `3px solid #993338` 外轮廓（`outline-offset: 3px`） |
| **在暖白底写 `#EE86A7` / `#BA8860` 小正文，或在浅橘/薄荷胶囊写白字** | 小字对比度仅 `2.4:1–2.9:1`，阳光或低亮度屏下难以辨认 | 小正文及链接使用 `#993338` / `#8E4C28` / `#8A5A36` / `#BF3B5E`（均 `>= 4.77:1`）；亮胶囊小字用 `#5C2226` / `#13463F` |
| **继续使用 `word-break: break-all`** | 把英文品牌词、日期和 URL 从单词中间生硬劈断 | 改用 `overflow-wrap: anywhere`，仅防长链接撑破窄屏 |
| **无跳过且阻塞首屏的开场动画** | 每次刷新或屏幕阅读器用户被迫卡在遮罩外等待数秒 | 默认直接进内容，或提供 `sessionStorage` 记忆＋显式 `<button>`「跳过」＋ `prefers-reduced-motion` 瞬时跳过 |
| **“盒中套盒”多重边框叠加** | `30px` 白岛里面又套带投影圆角大框，挤压行宽且显得杂乱 | 一层白岛内只用 `1px dotted` 虚线或淡樱 `#FFF4F7` 轻量分区 |
| **负边距锚点补丁（`padding-top: 110px; margin-top: -110px`）** | 让前一块的点击区与阴影意外压住上一节链接 | 在目标锚点上声明 `scroll-margin-top: 110px`（手机 `60px`） |

## 二、五维交付质量门禁核对单

### 1. 暖纸色调与 WCAG 对比度（Critical）
- [ ] 全站 `85%+` 面积保持暖纸（`#FDFFF2` / `#FBF8F1` / `#FFFFFF` / `#FAF4E0`），未混入冷灰或纯黑边框。
- [ ] 所有小正文、副标题、内联链接与和果子胶囊文字实测对比度 `>= 4.5:1`（主正文 `>= 6:1`）。

### 2. 丸体排版与商店街语调（High）
- [ ] 引入 `Zen Maru Gothic`（`500/700/900`）＋ `Noto Sans SC` / `Noto Sans JP`，启用 `palt` 且行高 `1.7–1.8`。
- [ ] 移除 `word-break: break-all`，正文宽度控制在 `<= 65ch`，长表与超长 URL 在窄屏不撑爆容器。

### 3. 页面原型与断点适配（Critical）
- [ ] 在 `1440×900`、`1024×768`、`834×1194`、`768×1024`、`375×812`、`320×568` 视口实测无横向溢出（`scrollWidth <= innerWidth`）。
- [ ] 地图/关系图、双色 `.tamako-chart`、汉堡全屏抽屉与大圆角白岛（PC `30px` / SP `15px`）在对应断点自然重排。

### 4. 键盘导航、ARIA 与减少动效（Critical）
- [ ] `:focus-visible` 焦点轮廓全站清晰不被固定顶栏或弹层遮住；手机菜单与手风琴正确同步 `aria-expanded` 并支持 `Escape` 关闭。
- [ ] 看板搭话气泡配有 `aria-live="polite"`；`prefers-reduced-motion: reduce` 下自动跳过开场幕布并停止平滑滚动与旋转/位移动效。

### 5. 性能、矢量资产与元信息（Medium）
- [ ] 小花、彩篷、虚线、箭头图标优先采用内联 SVG 与 CSS 渐变，不依赖整套高分辨率切图才能展示界面骨架。
- [ ] `<html lang>`、`<title>`、`meta description`、Open Graph、`scroll-margin-top` 与有效 `<button type="button">` 语义完整无遗漏。
