# 玉子市场通用设计理念 · Warm Arcade Storytelling

用蒸糯米的暖纸取代刺眼纯白，用豆沙褐红与焙茶暖棕取代生硬纯黑，让作品像兔山商店街清晨掀起的彩篷一样亲切、耐看、有人情味。灵感源自京都动画《玉子市场》（*Tamako Market*）及十周年纪念企划的商店街生活美学：哪怕载体不是动漫周边（例如市集导览、甜品/咖啡菜单、社区刊物、独立活动海报或宣传短片），都能借这套视觉语法做出柔软却秩序清晰、热闹而不嘈杂的设计。

> 若任务是设计、重构或评审 **玉子市场主题网站 / Web 应用**，先通读本理念，再按 [玉子市场网页设计规范 (`tamako-web`)](../tamako-web/SKILL.md) 执行语义 Token、流式丸体字阶、拱廊/糯米岛原型与无障碍门禁。

## 三条核心理念

1. **糯米暖底与豆沙字墨（拒绝生硬纯黑）**：以糯米象牙（`#FDFFF2`）、和纸暖白（`#FBF8F1`）与奶油底（`#FAF4E0`）承担大面积留白；正文与主墨色采用豆沙褐红（`#993338`）或焙茶暖棕（`#8E4C28`），彻底远离 `#000000` 粗黑描边与冰冷科技灰，把「温热食物与纸张」的质感贯穿全篇。
2. **樱饼主调与和果子色拍**：樱饼珊瑚粉（`#EE86A7` / `#FF7B82` / `#F66E75`）担任主情绪、章节领起与焦点锚点；黄豆粉杏橘（`#F69E6E` / `#DE9132`）、艾草叶绿（`#88B17D` / `#93D548`）、波子汽水薄荷（`#31CBB7`）与晴空蓝（`#428FDB`）仅按店招、场次或主题分组一对一分配，大面呼吸留白仍归暖纸。
3. **商店街的街坊招呼与手账针脚**：用「抬头见粉绿浅杏三色彩篷、进门有招牌吉祥物搭话」的邻里温度替代冷漠陈列——饱满丸体字配微调字距、团子式大圆角（`15px–30px`）、`dotted` 虚线针脚与麻色编织分隔线、白边金框相纸衬垫，以及领起章节的六瓣小花与圆胖小鸟符号。

## 五项基础视觉语法

| 维度 | 核心规范与色值 | 使用边界 |
| --- | --- | --- |
| **糯米纸与棕红字墨** | 纸面 `#FDFFF2` / `#FBF8F1`、奶油底 `#FAF4E0`、淡樱底 `#FFF4F7`；主字墨 `#993338` / `#8E4C28`；次级焦糖棕 `#8A5A36`。 | 正文区保持 `85%–92%` 暖纸/纯白留白；禁止使用冷灰黑或 `#000` 粗描边、厚硬黑影。 |
| **樱饼与和果子副色** | 主粉 `#FF7B82` / `#F66E75` / `#EE86A7`；黄豆杏 `#F69E6E`、艾草绿 `#93D548`、薄荷青 `#31CBB7`、晴空蓝 `#0EB2FF` / `#428FDB`、祭典蓝 `#2E62A2`；强调朱红 `#FF5B5B` / `#E4362D`。 | 每组卡片或按钮只分配 1 种和果子色表达分区身份；粉、橘、浅青等亮色块上放小字须加深墨确保可读性。 |
| **丸体排版与竖排引子** | 主体选用圆润饱满、字怀舒展的丸体（`Zen Maru Gothic` / `Hiragino Maru Gothic Pro`）；长段落配 `Noto Sans SC` / `Noto Sans JP`（行高 `1.7–1.8`）；开场引语可用传统竖排（`vertical-rl`）短句。 | 竖排与重字距仅用于 2–12 字开场诗句或店招；正文、时刻表与票务参数保持平直横排与左对齐。 |
| **团子圆角与手账分隔** | 容器采用如年糕团子般的柔和圆角（大岛 `24px–30px`、小卡 `15px`、缩略图 `6px–8px`、胶囊 `9999px`）；内部用 `1px–2px dotted` 针脚线或暖米横纹划界，配极轻暖棕漫射影（不用高对比硬切黑框）。 | 拒绝“盒中套盒”的嵌套重框；实景剧照与产品图外加 `3px–4px` 白/奶黄相纸边距和 `1px` 细金边（`#EDD18F`）或虚线边（`#CCCCCC`）。 |
| **小花小鸟与店方批注** | 用简化六瓣樱花或圆胖小鸟图标作为章节眉标；留言/攻略尾部可用暖橘红批注块模仿“商店街店主亲笔回复”。 | 符号只贴在板块一级题头或交互反馈旁，不密密麻麻铺满每个列表项；批注与正文保持同一亲切口吻。 |

## 按创作载体决定构图与节奏

- **街区导览与人物关系图**：以俯视街巷铺陈或「核心人物居中、家系与店铺向四周辐射」的亲缘放射图组织空间；热点与圆章之间留足呼吸空隙，每处地标弹窗控制在「名称 + 主图 + 一段风味简述」三层信息。
- **高吸睛封面、海报与缩略图（兼顾 `16:9` / `3:4` / `1:1`）**：先在手机端小缩略图尺度验证第一眼辨识度。顶部可用粉/薄荷/奶油三色浅彩篷条纹压住天际线，主标题以大字号樱粉或豆沙字居中或左右呼应；`16:9` 与 `3:4` 联动时把店招与核心人物锁在中央安全区，边缘留给街坊小物件与手写短句。
- **多卷商品、菜单与活动折页**：按「场次/卷别胶囊色标 → 实拍白框商品照 → 双色交替圆角规格表（左栏深粉项名、右栏白/淡樱交替说明）」排布；关键售价、日期或变更提醒用朱红（`#E4362D` / `#FF5B5B`）单点标出。
- **手记专栏与街坊留言板**：每篇笔记上方留出小鸟/小花图标题头与右对齐日期，正文行宽克制、段落短促带呼吸换行；读者来信下紧接一段店主/编辑团队的暖色短回信，营造双向对话的社区归属感。
- **宣传片与动态开场**：可用 `2–3` 秒暖白屏上的竖排手写短句（「那个女孩是可爱的／饼屋的女儿。」式日常悬念）切入真实彩色画面，末尾用轻量弹跳的街坊人物或招牌收尾，整体动效保持轻盈舒缓（`ease-out`、`200–500ms`），避免生硬闪切。

## 跨载体联动准则

把同一个企划拆成多种物料时（如主题网页＋活动海报＋导览折页＋宣传短片），**共享四样东西**：糯米暖纸与豆沙/焙茶棕红字墨、樱饼粉主色配和果子分类色拍、`Zen Maru Gothic` 圆润字标基因、以及六瓣花/虚线针脚/白边相纸手账语言；但**分开读者第一眼看到的重心**：海报只留主人物与一句竖排短钩子，导览折页突出地图热点与店铺动线，规格册/网页突出双色规格表与可展开的细节抽屉。

## 交付前三问（通用评审）

1. **去掉插画与底纹**：在纯暖白/奶油底上，标题、时间、地点与行动指引是否依然清晰耐读，且没有刺眼纯黑边框抢戏？
2. **退后两步看色序**：樱饼粉是否稳稳担任第一主角，其余杏、绿、蓝是否仅作有序点缀而未把画面涂成刺眼彩虹？
3. **感受人物与街坊温度**：整体是否有兔山商店街「刚出炉的点心配手账折页」的温润手工感，而不是冷冰冰的企业模板？
