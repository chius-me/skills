# 四色绘本设计语言

用图传达性格，用白纸和墨字承载信息。面对新任务，先确定读者最想找到的内容，再从真实题材里选一个能辨认的动作或物件。做维修手册时，可以画手怎样扣上卡榫；做书店海报时，可以画一叠书怎样从手推车滑下来。用同一种画法，就能让不同题材拥有各自的形象。

## 建立视觉层级

| 元素 | 用法 |
| --- | --- |
| 纸与墨 | 白色或接近白色的纸面承载长文、表格和输入区，深墨色 `#141419` 负责标题、正文、轮廓和选中态。让正文区安静，浅色短划、碎字或纸纹只在边缘和段间偶尔露出。 |
| 四个彩色 | 杏黄 `#F7B647`、浅粉 `#F09CB4`、草绿 `#99CB77`、珊瑚 `#EE847D` 是起始色板。在标识、栏目切换或章节圆点上重复相同色序。单个操作选一种强调色并配墨字；日期、单位等小字用深色。已有品牌色时，沿用品牌主色，给其余颜色分配稳定的辅助角色。 |
| 标题与字面 | 展示标题短而厚，字形略圆，可带手写起伏。正文用笔画开口清楚的无衬线体，字重从常规升到中粗，行高从 1.6 起调。字形最活泼的部分留给短标题；数字、长标题和连续段落保持稳定基线。双语时按信息主次定字号。 |
| 轮廓与留白 | 墨线勾出主图和重要入口，浅线分隔供比较的内容。用一处明显的大圆弧切进画面，文图区沿直边对齐；缩略图只取小圆角。先拉开内容组之间的空白，再微调组内间距。 |
| 插画与照片 | 手绘图用略有粗细变化的深线、平涂和轻微颗粒。让一个动作牵动另一个细节，近看能读出故事。作品、商品或步骤需要准确辨认时，保留实物照片，以相同取景、细墨框和题注与插画衔接。 |

## 按阅读任务决定构图

- **吸引目光、邀请探索。** 让一幅场景占主要面积。主物件远看有轮廓，小细节近看有因果；给日期、标题或控件预留一块干净的地方。内容具有真实空间关系时，可用路径串起地标，做成导览或可定位的大图。
- **浏览与选择。** 对象靠长相区分，用统一裁切的图和贴近图边的短题注；对象靠名称、时间或状态区分，用对齐的行。数字与名称分列，长标题只在自己的列里换行。读者向下扫时，日期或价格的位置应当可预测。
- **说明与叙事。** 采用单一阅读主轴。用一幅近景说明当前步骤或段落，图注贴图；多个步骤保持相同视角，只给变化的部件着强调色。把漫画式旁白、拟声字和跳出边缘的小插图用在确有语气转折的位置。
- **比较与操作。** 先摆出决定选择的差异，再放对应动作。版本、场次或课程切换共用固定位置，当前项用墨底反白；主要动作可用单色胶囊，文字写清结果。详情越密，装饰越往页边收。

## 让同一语言跨版面成立

**屏幕。** 宽屏可让横幅贴一边、正文面板从另一边伸出，以相对的两个大圆角建立呼应。窄屏先决定信息顺序，再裁图；时刻表可把名称移到时间上方，人物图仍保留能辨认表情的尺寸。交互中，圆形图标承载返回、播放、定位等短动作，切换项用带文字的按钮。装饰纹样可慢移，选择反馈应及时；开启减少动态效果时定格背景，直接呈现目的状态。

**静态版面。** 海报或展签保留同样的字形分工、四色顺序和直边对齐。用图例、引线、页码或章节圆点帮助阅读。远看先认主题和关键时间，近看再读注释。多张成套时固定刊头位置、题注样式和色序，每张可以换主体、景别和留白方向。

**同题迁移。** 以自行车维修为例，预约界面让服务和可选时段按行对齐，选中时间用墨底反白；维修手册用连续近景画出拆装顺序，以珊瑚色标出正在转动的零件；店内海报把同一零件放大成主图，以一条墨线引到日期。三种载体可以共用字标、色序和线条粗细，读者在每一张上先看到的东西各不相同。

## 评审时看三个地方

1. 暂时遮住插画，读者还能否找到标题、时间、下一步操作或文章起点？若信息埋进装饰里，先把关键文字移回纸面。
2. 把成品缩到手机宽度或退后几步看，主图还能否辨认，主标题与次要信息是否拉开？若所有东西一样抢眼，把四色集中到一个位置，给其余内容留白。
3. 并排看一张图多和一张字多的版面。它们应通过字、线、色序和对齐方式显出同一家族的关系。给纯文字页面加上同样的标题层级与页边，就可以收住风格。
