# 纸感等宽瑞士网格 · Paper Monospace Swiss

把瑞士网格的对齐、留白和信息秩序，用在带有纸感的个人站或阅读站上。靠字号、字重、对齐和间距排出层次；颜色主要指路，边框主要划界。等宽字体是这套风格的视觉主角。

具体默认色值、页面尺度与 `chius.me` / `chius.cc` 参考实现见 [参考预设](references/site-patterns.md)。

## 先按页面任务选布局

- **身份与去向（参考预设 `chius.me`）**：居中窄列。头像 → 粗体名字与可选的强调色句点 → 等宽、等距的链接行 → 一道细线和低调页脚。每行是一个完整点击目标；图标与文字居中成组，平台只保留图形识别，链接共用中性底色和同一交互样式。
- **索引与阅读（参考预设 `chius.cc`）**：外栏居中，内容沿同一左边线对齐。站名与导航分居页头两端，首页依次是简短引言、细线、分区标题和文章列表。列表以「可点标题 → 日期与阅读时间 → 摘要」重复排版，用留白区分条目。正文延续同一栏宽，靠标题、段落、可选目录和细线组织长文。
- 新页面按主要任务选一个骨架；同一站的多种页面可共享字体、语义色和对齐逻辑。头像、彩色句点、`#` 与 `↗` 按内容语义使用，无需凑齐；品牌名、域名前缀、图标与字体加载方式随目标站点调整。

## 把风格落到页面里

1. **先定容器与字阶。** 选一条主轴和有限的字号、间距档位。默认可用 Google Sans Code 排拉丁字符，中文内容可配 Sarasa Mono SC（或项目指定等宽/无衬线回退栈）；测试两者的基线、字重和中英混排行长。正文用常规字重，标题加粗，元信息缩小并降色；仅对合适的短拉丁标题收紧字距。
2. **用语义色切换整页。** 默认浅色预设是暖纸底、墨灰字、深蓝链接和少量砖红标记；深色预设是蓝灰底、浅灰字和杏色链接及标记（若目标站点另有品牌主色，只替换语义强调色并保持对比度）。默认跟随系统；有手动切换时保留选择。精确色值见 [参考预设](references/site-patterns.md)。
3. **让留白承担分组。** 首屏留出呼吸感，标题与所属元信息靠近，各段之间拉开距离。用 1px 细线标出页头、分区或页脚，用低圆角描边表面承载确实可操作的元素。文章列表保持开放；代码、搜索、目录等功能元素可拥有各自的浅底或边线。纸纹仅在链接页等短页作为可选的低透明度背景。
4. **保持状态清楚。** 正文链接用下划线，导航或列表可用下划线表示悬停或当前项。键盘焦点用醒目的虚线轮廓，悬停改颜色、线或底色即可，避免跳动。窄屏优先让导航、标题和元信息换行；代码和宽表格在各自容器内滚动。

## 实施与评审

实现或评审时，检查桌面和窄屏的主轴是否一致、浅深两色下链接和元信息对比度是否清晰、键盘能否辨认焦点。文章页用真实的长标题与中英混排检查换行和行距。有现有站点时先读它的容器、字体和主题变量，在现有技术栈内调整。
