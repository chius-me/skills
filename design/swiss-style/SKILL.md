# 纸感等宽瑞士网格 · Paper Monospace Swiss

把瑞士国际主义网格的对齐、留白和信息秩序，落到带有纸质呼吸感的个人站与阅读站上。等宽字体是视觉主角：靠字号、字重、对齐主轴与留白排出层次；颜色只负责指路，细线只负责划界。

按需查阅配套规范（避免一次性堆砌无关细节）：

- 精确语义 Token、对比度基准、符号/下划线语法与五类页面尺度：[预设色板与页面模式](references/site-patterns.md)
- AI 模板味避坑表、微文案准则、五维交付核对单与评审模板：[反模式、质量门禁与评审规范](references/quality-and-audit.md)

## 核心设计准则

- **结构即信息**：边框、细线、缩进、下划线线型与标点符号（`.`、`#`、`↗`、`←/→`）必须对应真实的信息关系，不做纯装饰填充。全站严守单一系统：一套容器宽度、一套间距与低圆角梯度、一套链接语法，且**描边容器最多嵌套一层**（严禁“盒中套盒”）。
- **把大胆留在一处**：页面的记忆点来自「等宽排版节奏 + 暖纸/蓝灰双色反差 + 贯通主轴 + 极少量砖红/杏色标点」，其余元素保持安静。完稿前做一次减法自检，删掉拿走后不影响阅读理解的外框、角标或眉题。
- **质量优先级底线**：空间或需求冲突时，按固定顺序取舍：**无障碍对比度与键盘焦点 > 触控目标尺寸与交互确定性 > 主轴对齐与中英混排可读性 > 字体/媒体性能与无脚本可用 > 视觉微调与打印样式**。

## 两遍式工作流

### 1. 先定方案并去模板化（Plan & De-slop）

- **改造现有站点**：先读工程的容器类名、CSS 变量、字体加载、多语言与构建配置，在原技术栈内收敛样式，严禁平铺第二套冲突的网格或工具类。
- **新建或重设计页面**：写代码前先给出四项极简设计单——**页面核心任务与对齐主轴**、**语义色 Token（4–9 个）**、**字体分工与目标行长**、**ASCII 骨架草图及本页刻意不放的元素**。
- **编码前自审**：对照 [AI 模板味避坑表](references/quality-and-audit.md#ai-模板味与反模式避坑表) 筛查方案。凡属通用生成式手癖（把开放列表切成带阴影圆角卡片、每个标题上方加全大写宽字距 Eyebrow、给非顺序条目强编 `01 / 02 / 03`、标题抽单个词换强调色、每屏滚动淡入上浮），一律在动代码前剔除。

### 2. 按页面任务选骨架

同一站点的不同页面共享字体栈、语义色与主轴逻辑，按核心任务选用骨架（具体尺寸见 [预设色板与页面模式](references/site-patterns.md)）：

| 页面原型 | 主轴与容器 | 结构节奏 |
| --- | --- | --- |
| **身份与去向**（预设 `chius.me`） | 窄栏居中（`37.5rem` 外框，`18.75rem` 内容栈） | 圆头像 → 紧字距粗体站名与强调色句点 → 等宽全行单色图标按钮栈 → 同宽 `1px` 顶线与低调页脚；可选极淡固定纸纹 |
| **首页与文章索引**（预设 `chius.cc`） | 外栏居中，内容严守同一左边线（最大 `48rem`） | 两端对齐页头（站名 + 导航与细线工具组） → 简短引言与社交图标 → `1px` 细线 → `#` 分区标题 → 靠留白分隔的开放文章列表 |
| **长文阅读页**（预设 `Chipaper`） | 延续 `48rem` 左对齐阅读栏，平面无噪点底色 | 面包屑 → 文章标题、元信息与 `#tag` → 可选薄线折叠目录（`<details>`） → 高行距正文（侧线引文、工具栏代码块、独立横滚宽表） → 句点收束与虚线上下篇导航 |
| **归档、标签与检索** | 延续 `48rem` 左边线 | 归档按年份分组并让等宽日期与标题基线对齐；标签页用词项加小字号计数；检索页用柔和底色单框输入配 `aria-live` 状态行，结果复用文章列表项 |
| **独立说明与异常页**（`About` / `404`） | 左对齐阅读栏（纯文页可收窄至 `42rem`） | 说明页将二级标题降为次级灰中字重以减轻压迫感；`404` 与空状态直说原因并给出明确返回路径 |

### 3. 把风格与工程纪律落到实处

1. **锁死主轴与等宽混排。** 默认拉丁字符用 `Google Sans Code`，中文配 `Sarasa Mono SC`（按 `unicode-range` 分片按需加载，或回退干净的系统等宽/无衬线中文字体）。正文用 `400`、按钮与小标签用 `500`、标题用 `700`，仅对短拉丁大标题收紧字距（`-0.025em` 至 `-0.055em`）。控制单行字数（拉丁 `< 75ch`、中文约 `32–42` 字），正文设 `line-break: strict`，长链接与内联代码设 `overflow-wrap: anywhere` 防止撑破窄屏。
2. **语义色切换与对比度守恒。** 界面保持 90%–95% 的暖纸或蓝灰中性面积：默认浅色为暖纸底 `#fdfcfb`、墨灰字 `#292c30`、深蓝链接 `#256786`、砖红标记 `#b24c37`；深色为蓝灰底 `#202530`、浅灰字 `#e1e5ed`、杏色链接与标记 `#eab38b`。目标站点有自定义品牌色时，只替换 `--accent` 与 `--mark`，分别实测浅/深背景及 `--soft` 柔和表面上的文本对比度（正文 ≥ `4.5:1`，主文本建议 ≥ `7:1`），禁用 `#000`/`#fff` 生硬纯色与廉价紫/霓虹渐变。默认跟随系统，支持手动切换记忆与防闪烁初始化。
3. **留白分组与线型分工。** 标题紧贴所属元信息，条目与章节之间靠充足留白拉开层次。`1px` 实线划定页头、引言、目录与页脚边界，`1px` 虚线用于文内 `<hr>` 与上下篇分隔。用下划线样式区分语义：常规链接用 `1px` 实线，正文内链与文章标题悬停用 `dashed` 虚线，主导航当前项与悬停用 `wavy` 波浪线。
4. **零位移反馈与瞬时焦点。** 悬停只改变字色、下划线或边框与底色（过渡 ≤ `180ms`），**严禁**卡片上浮（`translateY`）、缩放倾斜、视差或滚动渐显。`:focus-visible` 采用 `2px` 强调色虚线轮廓与外偏移，**不加过渡延迟**，且不被固定层遮挡。窄屏优先让导航与元信息自然换行，独立触控目标 ≥ `44×44px`，并在 `prefers-reduced-motion: reduce` 下关闭平滑滚动与过渡。
5. **克制微文案与渐进增强底座。** 文案只陈述真实内容与可执行动作：不用空洞套话，不捏造统计或访客评价；交互文案前后一致（如 `Copy` → `Copied`）；报错与空结果直接指路，不写拟人化道歉。`chius.me`、`chius.cc` 与 `Chipaper` 仅作为本 skill 内部参考预设，**不要**在产出项目的 README 或 Credits / 致谢里写“inspired by Chipaper / 致谢 Chipaper”这类自我致谢，仅致谢真正的第三方上游项目。补齐 `<html lang>`、Skip link、双主题 `theme-color`、图片显式宽高（首屏头像/主图 `fetchpriority="high"`，屏下 `loading="lazy"`）、代码块/宽表键盘可聚焦横向滚动容器、无 JS 降级隐藏与 `@media print` 打印样式。

## 验收与页面评审

- **构建自检**：交付前在 `1440 / 768 / 390 / 320` 宽度、浅/深双主题、纯键盘 `Tab` 与减少动态效果下逐项核验 [五维交付核对单](references/quality-and-audit.md#五维质量门禁核对单)，并用真实超长标题、中英混排段落与超宽代码/表格做压力检查。
- **独立评审**：当用户要求评审或优化现有页面时，若有运行环境先在浏览器中实测真实渲染与交互，再查源码定位根因；按 [页面评审协议](references/quality-and-audit.md#页面评审协议与报告模板) 以 `Blocker / High / Medium / Nit` 分级输出「观察现象 → 违反原则 → 修复方案」，同时指出值得保留的已有设计。
